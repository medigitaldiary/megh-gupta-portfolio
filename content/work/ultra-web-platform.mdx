## TL;DR

- Shipped the Ultra web app in 4 sequenced phases over 3 months, driven by explicit demand from the highest-LTV user segment.
- Phase 4 was web KYC, which unlocked web performance ads as a new acquisition channel the day it went live.
- Drove 15–20% True AUM growth and 30% new user acquisition from web in Q3 2025.

## Context

Ultra was mobile-only. Customer feedback over a 6-month window showed 18–20% of existing users, mostly 35–45 year old HNI professionals, were actively asking for a web platform. This segment wanted large-screen investment experiences during work hours, not phone-sized flows on a commute.

The signal was clean. The product question was how to sequence a full web build without waiting 6 months for the ideal release.

## Approach

Four phases, shipped sequentially, each tied to a specific user job. I chose phased over big-bang because any single phase on its own was already more valuable than the mobile-only status quo.

The sequencing call that mattered most was putting KYC last. On paper, KYC looks like foundational infrastructure that should ship first. In practice, I kept it in Phase 4 because web KYC was the unlock for a completely separate business goal: running web performance ads. Without web KYC, acquisition from the browser was blocked at the first step. With it, the whole channel opened.

## Execution

- **Phase 1 — Investment flows:** Deal discovery, deal viewing, investment execution. The core money-in journey.
- **Phase 2 — Wallet and escrow:** Adding money to wallet, deploying from wallet, withdrawals.
- **Phase 3 — Portfolio dashboard:** Investment tracking, payout schedules, performance views.
- **Phase 4 — End-to-end web KYC:** Complete onboarding without app dependency, which immediately unlocked web perf ads.

Each phase shipped with internal user testing before public release. All 4 phases went live before I moved to BondScanner.

## Outcome

15–20% True AUM growth from the web channel in Q3 2025. 30% new user acquisition in Q3 2025 via web-led performance campaigns, which only became possible after Phase 4 KYC shipped. Reduced session friction for the highest-LTV user segment, who were previously limiting their investment activity to phone-sized windows.

Qualitatively, Ultra stopped being seen internally as a mobile-only product. Sales and performance marketing started building web-first motions around it within a month of Phase 4 going live.

## Reflection

I'd run performance ads in parallel with the Phase 4 build instead of after. Even running a web perf acquisition pipeline on a landing-page-only funnel during build would have given us a 2-week head start on the data we were going to need to make the channel economics case.

## What I owned vs. team owned

- **I owned:** User survey, 4-phase product scope and sequencing, prioritisation call to put KYC in Phase 4, cross-phase measurement.
- **Team owned:** Front-end engineering build, KYC vendor integration (Digio), performance marketing campaign setup, design execution.
